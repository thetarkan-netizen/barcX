# barcX — Raf bazlı kör sayım (demo)

Deneme kaydı uygulama içine gömülüdür: **stok A / raf 86918091 / lokasyon a1-1**.

1. Raf barkodunu (86918091) okut.
2. KRL benzersiz etiket kodunu okut.
3. Stok A'yı seç ve fiziksel adedi gir.
4. Kaydet. Her okutma ayrı kayıttır. Aynı KRL için uyarı verilir.

Sistem adetleri bu demoda bulunmadığından yalnızca fiziksel sayım yapılır. Excel/CSV içe aktarma için stok, raf, lokasyon, opsiyonel raf barkodu sütunları kullanılabilir.

GitHub Actions > barcX APK > Artifacts altından başarılı derlemenin APK'sı indirilir.
